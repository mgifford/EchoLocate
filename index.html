Your transcript stays in this browser. Everything EchoLocate saves — captions, speaker labels and cards — is stored on this device only, and nothing is sent to GitHub. Speech recognition is provided by your browser: in Chrome and Edge that can send audio to the browser vendor's servers. EchoLocate has no server of its own.

⚠ HTTPS Required — EchoLocate needs a secure connection to access your microphone. Please open this via GitHub Pages or a local HTTPS / localhost server, not directly from the filesystem (file://).
⚠ Web Speech API not supported — This browser cannot run live transcription here. Try Google Chrome for the best experience. Microsoft Edge also supports it, but requires Use online speech recognition to be enabled in Edge settings.

Welcome to EchoLocate

Press Start and begin talking. Have a conversation and watch how voices are grouped. How accurate is it? Can you switch to another language? Try that too.

EchoLocate is open source and privacy-first, built so everyone can stand on the shoulders of giants.

Speech Recognition Not Available

Your browser does not support the Web Speech API required for live transcription.

Browsers that work with EchoLocate:

  • Safari (macOS / iOS) — works out of the box
  • Microsoft Edge — enable Use online speech recognition in Edge Settings → Privacy, search, and services → Services (edge://settings/privacy), then reload this page
  • Google Chrome 150+ — works in a regular (non-incognito) window; Chrome 149 and earlier have a known bug that prevents speech recognition from starting
